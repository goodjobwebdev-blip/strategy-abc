# Strategy ABC

Браузерная стратегия о древнем мире и Риме: глобальная кампания и схематичные тактические сражения, в которых решают строй, местность, манёвры и мораль.

Проект вдохновлён сочетанием кампании и сражений в Rome: Total War. Планируется собственная игра с более простой визуальной подачей, без заимствования чужих ассетов или кода.

## Состояние

Начальная подготовка репозитория. Сейчас доступны описание идеи и статический Hello World. Игровая симуляция, кампания, фракции и автобой ещё не реализованы.

## Запустить страницу

Из корня репозитория:

```sh
python3 -m http.server 8000
```

Открыть http://localhost:8000/. Зависимости и сборка для текущей заглушки не нужны.

## GitHub Pages

1. Открыть Settings → Pages.
2. В Build and deployment выбрать Source: **Deploy from a branch**.
3. Выбрать ветку **main**, папку **/(root)**, нажать Save.
4. Дождаться успешного развёртывания в Actions.

Адрес после включения публикации: https://goodjobwebdev-blip.github.io/strategy-abc/.
Демо: https://goodjobwebdev-blip.github.io/strategy-abc/hello-world/.
Эти адреса заработают после настройки Pages; наличие файлов само по себе не включает публикацию.

## Структура

```text
index.html            — точка входа приложения
styles.css            — оформление заглушки
.nojekyll             — публикация без Jekyll
hello-world/
  index.html          — визуальная заглушка
  main.js             — проверка JavaScript
docs/
  premise.md          — концепция игры

README.md
```

Следующий предлагаемый шаг — тактический прототип на TypeScript и Phaser. Решения о периоде, фракциях и правилах боя пока открыты.
