# Strategy ABC — Рим: северная граница

Играбельный браузерный MVP стратегии о древнем мире: глобальная кампания и схематичные тактические сражения. Строй, местность, манёвры и мораль влияют на исход боя.

**Играть:** https://goodjobwebdev-blip.github.io/strategy-abc/

## Что уже работает

- Географическая карта материковой Италии с реальными контурами Natural Earth, 12 городами, Альпами, Апеннинами, лесами, По и Тибром. Соседние земли пока служат фоном.
- Рим начинает с трёх отрядов: пехота, копейщики и лёгкая конница. Бойи на севере имеют два: галльские воины и лучники.
- Сухопутный маршрут рассчитывается через A*: море и горы блокируют движение, дороги почти вдвое уменьшают его стоимость. Через горы можно пройти по обозначенной дороге.
- Запас движения обновляется на следующий день, маршрут продолжается автоматически. Каждый римский город приносит 15 денариев за день.
- В городах доступны семь типов римских войск, содержание и пополнение с сохранением опыта. Крестьянский отряд стоит 35 денариев. Они присоединяются к армии на месте или ждут её в гарнизоне. Лимиты: 16 отрядов в армии и 8 в гарнизоне.
- Четыре типа процедурных тактических карт по месту встречи: равнина, лес, горы и город. Здания и скалы блокируют движение и обстрел.
- Ручной бой с паузой и скоростью 1× / 2× / 4×; выделение, движение, атака, поворот фронта и удержание позиции.
- Восемь типов войск, мораль, бегство и моральный удар по соседям, усталость, строй, кавалерийский натиск и особенности местности.
- Автобой на той же симуляции, где обеими сторонами командует ИИ.
- Потери переносятся в кампанию. Победа в поле даёт опыт и 100 денариев; Фельсину нужно занять отдельно, если бой прошёл в другом месте; поражение или ничья возвращают выживших в Рим.
- Тактический полигон с восемью типами отрядов, выбором местности и seed; он не меняет кампанию.
- Локальное автосохранение кампании и незавершённого боя. Загруженный бой начинает на паузе.

## Как играть

1. При необходимости найми крестьян в Риме.
2. Выбери Аримин, нажми «Марш к городу». Используй «Следующий день», если движения не хватило.
3. Двигайся к Фельсине; рядом с бойями появятся кнопки ручного боя и автобоя.
4. В ручном бою выбери свой отряд и нажми на сушу для движения или на противника для атаки. Shift добавляет точки в очередь; перетаскивание ПКМ задаёт место и фронт; рамка ЛКМ выделяет группу. Пробел — пауза.
5. Прикрой стрелков, обходи противника конницей и сохраняй свежий резерв. Все типы можно изучить на полигоне.

## Стек и запуск

TypeScript + Phaser 3.90.0, HTML/CSS. Vite предназначен для локальной разработки и обычной сборки; доступна также автономная сборка средствами Node.js с локальной копией Phaser.

Проверенный автономный путь, Node.js **22.18+**:

```sh
npm test
npm run build
python3 -m http.server 8000
```

Открыть http://localhost:8000/. Для этого пути не нужен npm install. Сборка удаляет и заново создаёт только `dist`, корневой `index.html` и содержимое `assets`.

Для разработки через Vite:

```sh
npm install
npm run dev
```

Проверка типов: `npm run check`. Сборка с Vite: `npm run build:bundle`. Эти команды требуют установленных зависимостей. Зависимости прямого уровня зафиксированы в package.json; lock-файл необходимо создать при первой полноценной npm-установке.

## Публикация

Текущая конфигурация GitHub Pages: **Deploy from a branch → main → /(root)**. Готовые `index.html` и `assets/` включены в репозиторий: после коммита в main Pages публикует их автоматически. Нельзя записывать только изменения TypeScript без повторной сборки.

После редактирования исходников выполнить `npm test` и `npm run build`, затем записать исходники и полученные файлы вместе. В дальнейшем этот шаг можно перенести в GitHub Actions. Менять текущую настройку Pages для MVP не требуется.

## MVP 0.5

Группы отрядов, очередь приказов, линия / рассыпной / глубокий строй, шаг / бег, стрельба по приказу, общая видимость армии с укрытием за высотами и зданиями. Пять задач боя доступны на полигоне. Бойи двигаются и угрожают городам; найм расширен, введены содержание, опыт и пополнение.

Камера: WASD, СКМ или Alt + ЛКМ, колесо и ±. Выбор: ЛКМ или рамка; Ctrl + 1–9 сохраняет группы, 1–9 выбирает. Приказ: ПКМ; Shift + клик добавляет продолжение. Перетаскивание ПКМ показывает будущую позицию и фронт строя. Поле 2400×1600, предварительная расстановка, закреплённая карта и отдельная прокрутка правой панели сохранены.

Подробнее: [правила и управление 0.5](docs/gameplay.md), [камера и расстановка](docs/viewport.md). Сброс: «Новая кампания» → «Начать заново». Старые экспериментальные сохранения не переносятся.

### Исправления тактики 0.5.1

Приказ атаки включает бег для конницы; штраф леса скорректирован. Отряды учитывают размеры строя при столкновениях и не проходят друг сквозь друга. ИИ держит стрелков за пехотой и ищет обход конницей. Групповое движение сохраняет расстановку игрока; поворот вращает её целиком. [Подробности и проверки](docs/tactical-fixes.md).
